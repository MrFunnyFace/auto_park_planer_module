Как создать расписание для водителей? ▼

Для создания расписания выполните следующие шаги:

  1. Перейдите в раздел "График работы"
  2. Нажмите кнопку "Создать расписание"
  3. Выберите период планирования
  4. Назначьте водителей на смены
  5. Сохраните и опубликуйте расписание
Как установить лимиты расходов? ▼

Для установки лимитов:

  1. Откройте раздел "Управление лимитами"
  2. Нажмите "Создать новый лимит"
  3. Выберите тип лимита (километраж, топливо, время)
  4. Укажите значение и период действия
  5. Настройте уведомления при превышении
Как просмотреть отчет по расходам? ▼

Для просмотра отчетов по расходам:

  1. Перейдите в "Экономика автопарка"
  2. Выберите период анализа
  3. Настройте фильтры по типу расходов
  4. Нажмите "Обновить" для загрузки данных
  5. Используйте кнопку "Отчет" для экспорта
Как прогнозировать потребность в транспорте? ▼

Система прогнозирования позволяет:

  • Анализировать историческую нагрузку
  • Учитывать сезонные факторы
  • Планировать ресурсы на будущие периоды
  • Получать рекомендации по оптимизации

Перейдите в раздел "Планирование ресурсов" и следуйте подсказкам системы.

Что означают статусы в системе? ▼

Цветовые обозначения статусов:

  • Зеленый - норма, активное состояние
  • Оранжевый - предупреждение, требует внимания
  • Красный - критическое состояние, требует действий
  • Синий - информационный статус
Как получить техническую поддержку? ▼

Для получения технической поддержки:

  • Обратитесь к системному администратору
  • Проверьте данный справочный раздел
  • Используйте встроенные подсказки (наведите курсор на элементы интерфейса)
